# Injaazh Design System

## Philosophy

Build a premium enterprise SaaS CRM inspired by Linear, Attio, Stripe
Dashboard, Vercel, Notion, Arc Browser and Raycast. Never copy any
product directly.

## Colors

-   Background: #09090B
-   Background Secondary: #0F1117
-   Card: #11131A
-   Border: #232734
-   Primary: #2563EB
-   Accent: #7C3AED
-   Success: #10B981
-   Warning: #F59E0B
-   Danger: #EF4444
-   Text Primary: #FFFFFF
-   Text Secondary: #B4BCD0

## Typography

-   Heading: Plus Jakarta Sans
-   Body: Inter

## Radius

-   Card: 24px
-   Button: 16px
-   Input: 14px
-   Badge: 999px

## Layout

-   12-column grid
-   8px spacing system
-   Desktop-first
-   Responsive for Desktop, Laptop, Tablet and Mobile

## Components

Always reuse: Button, Card, StatCard, SearchBar, FilterBar, DataTable,
Drawer, Modal, Skeleton, EmptyState, Pagination, StatusBadge.

## Animations

Use Framer Motion. Duration: 200ms. Use fade, slide and subtle hover
lift only.
