# UI / UX Rules

## Goal

Every page must look like it belongs to the same product.

## Dashboard Consistency

Match: - Colors - Typography - Shadows - Radius - Spacing - Buttons -
Icons

## Tables

Never look like Excel. Rows should feel like interactive cards.

## Forms

-   Clear labels
-   Inline validation
-   Helpful empty states

## Responsive

Desktop: - Sidebar expanded - Full table

Tablet: - Collapsible sidebar - Compact filters

Mobile: - Bottom navigation - Card layout instead of table - Floating
primary action

## Micro Interactions

-   Hover lift
-   Smooth transitions
-   Animated progress bars
-   Drawer animations

## AI Rule

Before generating UI: 1. Analyze task. 2. Reuse existing components. 3.
Maintain design consistency. 4. Do not redesign existing patterns unless
requested.
