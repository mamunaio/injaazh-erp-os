# Development Rules

## Stack

-   Next.js 15 App Router
-   TypeScript
-   Tailwind CSS v4
-   shadcn/ui
-   Zustand
-   React Query
-   React Hook Form
-   Zod
-   Lucide React
-   Recharts

## Architecture

-   Feature-based folders
-   Reusable components
-   API service layer
-   No duplicated logic
-   No direct fetch in UI components

## Quality

-   Production-ready only
-   Strong typing
-   Clean code
-   Small components
-   Accessibility required
-   Skeleton loading required
-   Error boundaries and friendly errors

## Performance

-   Dynamic imports
-   Lazy loading
-   Memoization
-   Server Components when appropriate

## Checklist

Before every commit verify: - Responsive - Type-safe - Accessible -
Reusable - Tested manually
